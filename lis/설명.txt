송파바로 케어 노트 · LIS 결과 자동 감지 (서버 PC 전용)

[처음 설치 - 한 번만]
1. 받은 zip을 압축 풀고, 안에 있는 install.bat 을 더블클릭합니다.
   (윈도우가 "PC 보호" 경고를 띄우면 "추가 정보 → 실행")
   - C:\songpabaro-lis 에 자동으로 복사되고, PC 켤 때 자동 실행으로 등록됩니다.
   - 진단 창이 뜹니다.
2. 처음이면 진단 창에 "승인 대기 중 ... 코드 XXXXXX" 가 뜹니다.
   원장님 폰 케어 노트 🔐 기기 관리에서 "서버PC LIS 연동"(같은 코드)을 승인합니다.
3. 검사를 하나 돌려서 진단 창에 "[진단] 읽은 글자: ... 자료 수신 ..." 이 뜨는지 확인합니다.
   - 확인되면 진단 창은 닫아도 됩니다. (다음 부팅부터 자동으로 조용히 실행)
   - 안 보이면 진단 창 사진을 보내 주세요.

[업데이트 - 할 일 없음]
- 프로그램이 1시간마다 새 버전이 있는지 스스로 확인하고, 있으면 알아서 바꾸고 다시 시작합니다.

[하는 일]
- IntoVET_LIS 창 아래 상태줄의 글자만 읽습니다. 인투벳·LIS·DB에는 아무것도 쓰지 않습니다.
- 동물번호(ID)가 같은 진행 중 검사 오더에 "📥 결과 도착"을 표시하고,
  오더에 필요한 기계 결과가 모두 오면 검사실을 자동 완료로 바꿉니다.
- 결과가 들어오면 케어 노트를 켠 모든 PC의 우측 아래에 알림이 뜹니다.
  소리는 케어 노트에서 '오더 소리'를 켠 PC(접수실2)에서만 납니다.
- 요검사처럼 기계로 안 들어오는 항목이 섞인 오더는 자동 완료하지 않고 "결과 도착"만 표시합니다.

[보안]
- 다른 기기와 똑같이 원장님 승인을 받은 기기로만 케어 노트 데이터에 접근합니다.
- 로그인 정보와 기록은 이 PC의 %APPDATA%\songpabaro-lis 폴더에만 저장됩니다.
- 자동 업데이트는 병원 저장소(songpabaro-care.github.io)에서만 받습니다.
- 끄기: 작업표시줄 "SongpaBaro LIS" 창 닫기 / 자동 실행 해제: Win+R → shell:startup → "SongpaBaro LIS" 바로가기 삭제
